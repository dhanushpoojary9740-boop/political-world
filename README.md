# Political World — Milestone 1

Fresh Godot 4 starter project for the Political World India + global politics simulation.

## Included in this milestone
- Monthly world calendar.
- Starter party and politician data.
- Party popularity and basic recurring funds.
- AI election-cycle demonstration.
- Automatic candidate selection for eligible party members.
- Player authority is framed as party high command in Karnataka; AI handles other simulated states.
- A simple mobile-friendly prototype screen.

## Important prototype limitation
This is a foundation prototype, not the complete election or government simulation. The election demonstration currently runs in July and resolves one simplified seat per simulated state. Before expanding, replace this with constituency-level candidate registration, campaign actions, voting, seat allocation, coalition formation, and strict office-based authority checks.

## Open in Godot
1. Download and extract the ZIP.
2. In Godot 4, choose **Import** and select `project.godot`.
3. Open the project and press **F6** or **F5** to run.
4. On Android, use Godot's Android export setup when the project is ready for APK packaging.
